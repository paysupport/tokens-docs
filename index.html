Tokens

管理逆向 Token 的平台 — 一个控制台，管理你的所有模型访问凭证。

Tokens 将多个上游模型的访问统一到一组 API Key 之下。你只需要在控制台创建一个 Token，即可用同一套接口调用不同的模型；额度、速率与日志都在一处查看。

快速开始

登录 控制台，在「令牌」页面创建一个新的 Token，然后把它放进请求头：

curl https://api.cometapi.com/v1/models \
  -H "Authorization: Bearer $TOKEN"
Token 只在创建时显示一次，请立即保存。丢失后可以重新生成，旧 Token 会同时失效。

Token 管理

字段说明
名称用于区分不同项目，例如 prod-web
额度该 Token 可使用的最大额度，留空表示跟随账户
过期时间到期后自动失效，可随时续期
模型范围限制该 Token 可调用的模型

额度与计费

每次调用按输入与输出 token 计费，账单在控制台的「日志」中逐条可查。额度不足时接口返回 403，充值后立即恢复。

API 调用

接口与 OpenAI 兼容，只需替换 base_url：

from openai import OpenAI

client = OpenAI(
    api_key="sk-...",
    base_url="https://api.cometapi.com/v1",
)
print(client.models.list())

常见问题

Token 与账户密码有什么区别？ Token 只用于接口调用，不能登录控制台；泄露后请在控制台吊销。

可以在多个项目中共用一个 Token 吗？ 可以，但建议按项目拆分，便于统计与吊销。
